# [T006] 实现登录、Session 和账号安全

阶段：M1  
需求依据：FR-01、AC-02、NFR-06  
前置任务：[T003 #3](https://github.com/bao-linfeng/exhibition-ai/issues/3)、[T004 #4](https://github.com/bao-linfeng/exhibition-ai/issues/4)

GitHub Issue：[#6](https://github.com/bao-linfeng/exhibition-ai/issues/6)；PR：尚未创建。

## 目标与范围

实现登录/退出/me、Argon2id、数据库Session、Origin/CSRF、限流、首登改密和本人改密；受控容器命令初始化管理员及重置临时密码。

## 验收清单

- [ ] 空闲8小时/绝对7天过期、退出和停用失效；凭证不进localStorage
- [ ] 可信Origin/CSRF及登录限流有正反测试；生产Cookie配置符合基线
- [ ] 无默认生产密码，容器命令不打印密码；首登必须改密
